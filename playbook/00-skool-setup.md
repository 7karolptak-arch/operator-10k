# Skool setup — OPERATOR Founding Class

Paste this as you build the community. No videos required to open the classroom.

## Community

- **Name:** OPERATOR
- **Headline:** 8-week execution program. First B2B service. Target: 10,000 PLN/month.
- **About (pin):** Operator 10K is an execution path, not a content library. You pick one market, build one offer, talk to companies, sell, deliver, and run a weekly rhythm. 10k PLN/month is the **target of the system**, not a guaranteed income. We give process, scripts, and live correction. We do not make the calls for you.
- **Welcome post:** Week 0 rules + link to Classroom “00 — Start here”.
- **Levels:** Applicant → Operator → Founding Class (manual, first 25).
- **Rules:** No income screenshots without context. No “guaranteed 10k” talk. Post numbers weekly (touches, conversations, offers, cash). No lurker inspiration posts.
